# IpamCalculadora

Calculadora para Android desarrollada en Kotlin.

## Requisitos

- Android Studio (última versión estable)
- JDK 11+
- Android SDK API 35

## Configuración y Ejecución

2. **Sincronizar:** Esperar a que el proceso de `Gradle Sync` finalice automáticamente para regenerar archivos locales (`.idea`, `local.properties`).
3. **Compilar (Terminal):**
   - Linux/macOS: `./gradlew assembleDebug`
   - Windows: `gradlew.bat assembleDebug`
4. **Ejecutar:** Seleccionar dispositivo (Emulador o Físico) y presionar `Shift + F10` o el botón `Run`.
